Six ways to be more than a padlock

A lock says “security” and nothing else, so every vault and password manager looks the same. These directions each borrow something specific to cfs: masked values, .env files, Cloudflare, the audit chain, the CLI, and end-to-end sealing. Check each one at 16px, because that is where favicons live.

My pick: A, with B for the docs

A is the only one that comes from how the product actually looks: values shown as dots. Use it as the app icon and the sidebar logo, and write “cfs” beside it in Space Grotesk Bold. Keep B for the documentation and CLI help, where the braces tell developers it’s about .env and JSON. If the favicon turns to mush at 16px, draw a two-dot version just for that size.
