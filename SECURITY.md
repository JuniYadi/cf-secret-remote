# Security policy

Only the latest release is supported with security fixes.

## Reporting a vulnerability

Report vulnerabilities through GitHub Private Vulnerability Reporting in this repository's Security tab. Do not open a public issue. We aim to acknowledge reports within 3 days and assess them within 7 days.

The scope includes the Worker, web app, CLI, extension, `packages/core`, and install scripts. A compromised Cloudflare account or browser is out of scope; see the [threat model](docs/threat-model.md). Volumetric denial of service is also out of scope.

We welcome good-faith security research. We will not pursue legal action for research that avoids privacy violations, data destruction, and disruption to others and gives us a reasonable opportunity to fix the issue. There is no paid bounty.

We release fixes with a GitHub Security Advisory and a CVE when applicable.
